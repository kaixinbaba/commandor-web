PRIVACY

Local by default.

Commandor is an early-stage independent fork. The current build keeps upstream cloud sign-in and relay disabled unless an operator explicitly supplies compatible backend configuration.

Local application data

Project paths, worktree metadata, terminal state, settings, and logs are stored on the device running Commandor. Connected developer tools and providers may have their own data practices.

Telemetry

Telemetry is fail-closed in unofficial builds without an explicitly configured project key. Do not assume this page covers third-party CLI agents, GitHub, GitLab, Linear, or model providers you connect.

Feedback

No Commandor feedback API is currently operated. Please use GitHub Issues and remove secrets or sensitive logs before posting.

Status

This is a plain-language project notice, not a final legal policy for a commercial release. It will be revised before hosted accounts, analytics, or paid services launch.
